# V1 功能范围与验收边界

## 产品角色

| 角色 | 职责 |
| --- | --- |
| 平台管理员 | 模型、凭证、业务系统客户端、全局策略、备份和组件健康 |
| AI 管理员 | 应用、Agent、Prompt、Skill、Workflow、工具、评估与发布 |
| 知识管理员 | 知识库、来源、文档、切片、索引、检索测试与权限 |
| 数据管理员 | 数据源、允许对象、字段语义、指标、查询策略与审计 |
| 报表管理员 | 报表定义、模板、调度、发布、重跑与制品管理 |
| 审计人员 | 只读查看模型、Agent、工具、数据查询和高风险操作记录 |
| 业务系统客户端 | 通过机器凭证调用已发布应用，查询任务和获取制品 |
| 内部用户 | 在权限范围内调试或使用已发布 AI 应用 |

角色是默认职责模板，最终授权仍落到现有 `domain:resource:action` 权限点和数据范围规则。

## 一级能力与首版验收

### 1. AI 应用与 Agent 管理

- 创建 AI 应用并绑定一个已发布 Agent 或 Workflow 版本。
- Agent 支持指令、模型路由、Prompt、Skill、工具、知识库、记忆和运行策略配置。
- 草稿、发布、停用和回滚状态明确；运行只引用不可变已发布版本。
- 支持在线调试、流式结果、运行取消、失败原因和版本差异查看。
- 删除前检查业务系统、任务、报表和历史运行引用，不允许形成孤儿关系。

### 2. Prompt、Skill 与 Harness

- Prompt 和 Skill 支持独立版本、发布、回滚、引用检查和测试样例。
- Skill 采用元数据摘要加按需加载正文，正文不能隐式获得未授权工具。
- Harness 策略至少覆盖最大模型调用、最大工具调用、超时、上下文压缩、重试、人工审批和输出约束。
- 运行时将最终使用的模型、Prompt、Skill、工具、策略版本写入运行快照。

### 3. Workflow、任务与人工介入

- Workflow 支持顺序、条件、并行、循环、Agent、工具、人工审批和结束节点。
- 支持草稿验证、版本发布、流式执行、中断、恢复、取消、超时和失败重试。
- 定时、事件和人工触发均创建统一任务记录；重复触发遵循业务幂等键。
- 人工审批支持批准、修改参数和拒绝，决策人、决策内容与恢复点可审计。

### 4. 会话、上下文、记忆、Workspace 与制品

- 会话区分用户消息、模型消息、工具消息和系统事件，保留稳定顺序。
- 短期上下文、长期记忆和运行 Workspace 分开存储与授权。
- 上下文压缩保留来源事件，不能用摘要覆盖原始审计记录。
- Workspace 文件经现有文件服务保存，记录创建者、运行、用途、敏感级别和保留期。

### 5. 模型接入、路由与统计

- 管理 OpenAI 兼容、DeepSeek、通义和私有模型端点；Chat、Embedding、Rerank 类型分开。
- 密钥只在创建或轮换时写入，之后只返回已配置状态；测试连接不得回显凭证。
- 支持模型别名、主备路由、超时、限流、熔断和显式降级，禁止静默换用能力不等价模型。
- 每次调用记录供应商、端点、实际模型、状态、首 Token、总耗时、输入/输出/缓存 Token 和价格版本。
- 统计支持按时间、业务系统、应用、Agent、用户、模型和供应商查看请求、成功率、Token、延迟和成本。
- 价格变化新增版本，不修改历史；本地模型允许配置内部核算单价或仅统计资源用量。

### 6. 知识库

- 支持文件上传和受控数据源同步，具有文档版本、解析、切片、索引和失败重试状态。
- 检索支持关键词、向量、混合、元数据过滤、TopK、阈值和重排配置。
- 回答可以返回文档、版本、切片和页码等引用；无证据时不能伪造来源。
- 用户、Agent 和业务系统只能检索已授权知识库；权限过滤必须在召回前或召回查询中执行。
- 支持增量更新、重建索引、软删撤索引和失败任务诊断。

### 7. 数据接入与语义层

- 数据源凭证加密保存，连接测试和查询均有超时、并发和出站地址策略。
- 首版只允许只读数据库账号和显式登记的 Schema、View 或表；客户优先提供只读视图。
- 元数据快照与人工维护的字段解释、枚举、关联和指标定义分开。
- 指标由确定性 SQL/表达式计算；LLM 可以选择已发布指标，不能改写指标口径。
- 自然语言查询生成结构化查询计划，经过对象、字段、语句类型、行数、时间和成本检查后执行。
- 查询记录操作者、Agent、数据源、归一化 SQL 摘要、返回行数、耗时和策略决策，不记录凭证明文。

### 8. MCP、API、数据库与内置工具

- 工具具有版本、输入输出 Schema、超时、重试、副作用级别、所需权限和凭证引用。
- MCP Server 支持启停、健康、工具发现和工具快照；运行使用发布时工具快照，避免远端静默改变行为。
- 外部 HTTP 工具使用目的地址策略、重定向限制、响应大小上限和敏感字段清理。
- 数据库写入、文件写入、外部通知等高风险工具必须配置人工审批或明确的服务授权。
- 工具调用按 Agent、会话和运行记录输入摘要、输出摘要、状态和耗时；L3/L4 正文默认不进入日志。

### 9. 开放平台与前端集成

- 管理页面全部位于现有 Vue 应用，浏览器不直接访问模型网关、向量库和运行时管理端。
- 业务系统通过 `/open-api/v1/**` 和独立机器凭证访问，支持 Scope、轮换、过期、撤销、限流和审计。
- 提供同步流式调用、异步任务、任务查询、取消、回调和报表制品访问。
- 对创建任务和报表生成命令支持 `Idempotency-Key`；同键不同请求体返回冲突。
- 发布后保持 N/N-1 API 兼容；破坏性变更进入新版本。

### 10. 报表与可视化 HTML

- 报表定义绑定数据集、指标、分析 Agent、受信模板、图表和发布策略的具体版本。
- 先生成确定性数据快照，再让模型生成结构化叙述，最后由渲染器生成 HTML。
- 模型不能输出可直接执行的 HTML、JavaScript 或 SQL；文本默认转义，图表使用受控 Schema。
- 支持人工审核、定时生成、手工重跑、版本对比、制品下载和业务系统回调。
- 报表保留输入数据快照摘要、引用、模型版本、Prompt 版本和生成记录，支持重现与审计。

### 11. 可观测、评估与运营统计

- Trace 关联业务请求、Agent Run、模型调用、工具调用、检索和报表运行。
- 提供成功率、延迟、Token、成本、工具失败、检索命中、人工介入和任务积压指标。
- 评估支持数据集、规则评估、代码评估、LLM Judge、人工评分和版本对比。
- 统计指标不能包含原始密钥、完整 Prompt、完整文档或高基数敏感标签。

### 12. 私有化部署与运维

- 提供统一健康页，区分 Java 应用、MySQL、Redis、模型网关、检索和模型端点状态。
- 生产配置缺失、默认密钥、不可达依赖和不安全出站策略在启动或发布检查时 fail closed。
- 提供离线镜像清单、版本矩阵、许可证/SBOM、备份范围、迁移顺序和回滚说明。
- 保持现有 RTO 4 小时、RPO 1 小时基线；模型与检索索引可重建，但领域元数据、审计和制品必须备份。

## 首版非目标

- 多租户 SaaS、租户套餐、跨租户运营和租户计费。
- 模型训练、微调、GPU 调度和模型权重生命周期管理。
- 允许用户上传任意 JavaScript、Python、Shell 或服务端模板并在主应用执行。
- 不经对象和字段授权的任意数据库自然语言查询。
- C 端社交、角色陪伴、公共 Agent 商店和开放注册。
- 用第三方平台 UI 替代统一前端。

## 首版完成定义

首版不是页面存在即完成。每项一级能力必须同时满足：

1. 管理端权限、正常流程、边界校验和错误路径闭环；
2. 机器接口具有版本、认证、限流、幂等和审计；
3. 关键数据具有迁移、生命周期、备份和恢复策略；
4. 外部组件故障有明确错误语义、超时、重试边界和诊断信息；
5. 单元、API、集成、制品启动和至少一条真实模型验收路径通过；
6. 文档、SBOM、许可证、部署和升级说明与实际制品一致。
