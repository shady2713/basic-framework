# 管理后台威胁模型

范围为浏览器管理端、Spring 应用、MySQL、Redis、文件存储及短信/对象存储等外部适配器。
增加开放 API、多租户、SSO 或富文本前必须先修订本文。

## 资产与信任边界

关键资产是 L4 凭证、L3 个人信息、权限与配置完整性、服务可用性和审计可信性。

1. 浏览器或网关到 Spring 应用；
2. 应用到 MySQL、Redis 和本地文件系统；
3. 应用到短信、对象存储等外部服务；
4. 管理员控制面到凭证、权限、任务和代码生成能力。

## 威胁与控制

| # | 威胁 | 当前控制 | 必须保持的边界 |
|---|---|---|---|
| T1 | 爆破、撞库和账号枚举 | 登录、短信和重置入口按客户端 IP 限流；统一失败文案；管理员 MFA | 限流存储异常时不得静默放行；公开认证入口不得增加自助注册 |
| T2 | Token 伪造、窃取和重放 | CSPRNG；数据库/Redis 仅存摘要；refresh Cookie 隔离并单次轮换；账号和权限变化撤销会话 | refresh token 不得作为 access token；原始 token 不得进入日志、管理页或持久层 |
| T3 | 越权和控制面接管 | 默认要求认证；Controller 声明权限；高风险命令服务端 `@MfaStepUp`；精确集合测试防回退 | 新入口必须定性为公开、认证或专用权限；页面隐藏不构成授权 |
| T4 | 路径穿越、恶意压缩包和文件泄露 | canonical path 边界；ZIP 条目数、展开量和压缩比限制；存储类型白名单 | `/infra/file/{configId}/get/**` 是公开读取面，只能承载明确允许公开的对象，不能以不可猜路径代替鉴权 |
| T5 | SQL、模板、命令和 XSS 注入 | MyBatis 参数化；排序 allowlist；代码生成引用校验；统一 XSS cleaner；禁用富文本和动态脚本 | 不使用字符黑名单；代码生成器只读取部署配置的主数据源，不接受运行时 JDBC 凭据 |
| T6 | SSRF 与内网横向访问 | 文件适配器使用类型白名单；外部地址由受权限配置持有 | JDBC、回调和对象存储端点不能只做 URL 语法校验；部署层必须限制出站网络，新增主动抓取能力前实现统一目的地址策略 |
| T7 | 秘密或个人信息泄露 | 数据分级；敏感日志清理；L4 默认禁出；高风险配置读取要求 step-up | 可恢复秘密必须 AES-GCM 存储；含秘密对象不得生成完整 `toString()` |
| T8 | XSS、CSRF 与浏览器侧伪加密 | 无富文本；统一外链入口；refresh Cookie `SameSite=Strict`；浏览器端不保存解密私钥 | TLS 是传输保密边界；credentialed CORS 只能使用显式来源白名单 |
| T9 | 供应链和凭证误提交 | Maven/pnpm 锁定版本；前端生产依赖审计；lefthook secret scan | Maven 漏洞扫描例外受 `docs/exceptions.yaml` 到期门禁约束 |
| T10 | 消息重复、丢失和任务重放 | Redis Stream at-least-once、inbox 幂等、有限重试、DLQ 后 ACK；Quartz JDBC JobStore | 消费副作用必须幂等；人工回放、丢弃和立即执行必须鉴权、step-up 并审计 |

## 不接受的风险

- 公开创建后台账号；
- L4 正文出现在日志、异常响应、指标标签或管理列表；
- 用浏览器内置密钥、路径不可猜或前端按钮隐藏代替 TLS、鉴权或服务端授权；
- 文件访问越出配置根目录；
- 未验证归属的跨模块写入或未登记的数据生命周期关系。
